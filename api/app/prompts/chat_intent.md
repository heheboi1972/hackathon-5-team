## intent 목록
`fact_query` / `metric_query` / `report_query` / `term_count` / `advice_request` / `other`

## 고정 규칙

**`term_count` — 단어 횟수 질문** ("사랑해 몇 번 썼어?", "치킨 얼마나 자주 나왔어?")
- LLM 이전에 regex 로 먼저 잡는다: `몇\s*번`, `몇\s*회`, `얼마나\s*자주` → 대상 단어 추출
  (따옴표 안이 있으면 우선, 없으면 패턴 앞 어절). regex 가 실패할 때만 LLM 이 단어를 뽑는다.
- 답변은 `count_term` 툴 결과로 만든 템플릿 문장. LLM 이 숫자를 만들지 않는다 (P-2).
- **커플 합산만 답한다.** "내가 몇 번", "쟤가 몇 번" 처럼 사람을 지목해 물어도 합산으로 답하고
  "누가 얼마나 썼는지는 알려드리지 않아요" 를 덧붙인다 (P-3 예외 보호).
- 이 답변에는 인용을 붙이지 않는다 — 인용 카드가 발화자를 드러내기 때문. 숫자와 주별 추이가 근거다.
- 0건이면 지어내지 말고 "'{단어}'은 대화 기록에서 찾지 못했어요".

**`advice_request`** — 검색 없이 고정 리다이렉트 문구, `answer: null`.
**`other`** — 허용 집합 밖은 모두 여기로. "대화 기록·지표·리포트에 대해 물어봐 주세요".
