# 금지 표현 regex (FR-004, P-1) — 한 줄에 하나. `#` 줄과 빈 줄은 무시.
# 검수 대상: LLM 이 만든 문장 = highlights[].observation / interpretations[] / suggestions[].text
#   moments[].text 는 코드가 만들고 수치가 근거라 대상 아님 (TRD §5.2).
# 검사 시점: names.ts 가 A/B → 실명으로 바꾸기 **전**, 서버에서. 그래서 인물 규칙은 A/B 토큰 기준.
# 초안: 해찬. 검수·보강은 윤아 (TASKS 2-12).

# ── 1. 인물 지목 (ISSUE B3 — who 가 계약에서 사라졌으므로 문장에도 나오면 안 된다)
\b[AB]\s*(가|이|는|은|의|님|씨)\b
(님|씨)\s*(가|이|는|은|의)\s

# ── 2. 두 사람 비교 ("우리는 ~한 편이에요" 로만)
(더|훨씬|덜)\s*(많이|자주|빨리|늦게|길게|짧게|적게|잘|오래|먼저)
(상대방?|파트너|한\s*쪽|다른\s*쪽|[AB])\s*(보다|에\s*비해)
(누가|어느\s*쪽이)\s*(더|덜)

# ── 3. 수치 (ISSUE B3 — 프롬프트에 방향·정도만 넘기므로 문장의 숫자는 근거 없는 값)
#    "지난 4주에 비해" 처럼 기준선을 가리키는 표현은 비교가 아니므로 막지 않는다
\d+\s*(%|퍼센트|배|점|등급)

# ── 4. 점수·등급 (P-1)
관계\s*온도
[ABCDF]\s*등급

# ── 5. 가치 판단 (P-1)
(좋아졌|나빠졌|악화|개선되)
(건강한|위험한|바람직|이상적인)\s*(관계|사이|커플)

# ── 6. 원인 단정 (P-1, P-4)
때문(에|이)

# ── 7. 명령·당위 (P-1)
(하세요|해보세요|하셔야|해야\s*(해|합니다|해요))
(반드시|꼭)\s*

# ── 8. 관계 판정 (P-1)
(헤어지|이별|결별)
(잘\s*맞|안\s*맞|궁합)
