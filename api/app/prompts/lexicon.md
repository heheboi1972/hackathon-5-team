# build_lexicon — 커플 단어 분류 프롬프트 (ISSUE A1, Phase 3)

## 계약

입력: 단어 + 최초 등장 3건의 앞뒤 2~3토큰 예시. 100단어씩.
출력(JSON): `[{"term", "canonical", "polarity": "pos|neg|neutral|exclude"}]`
규칙: canonical 은 철자 변형만 묶는다(조아→좋아). 동의어는 분리. exclude = 욕설·이름·호칭(자기야 등)·식별정보. 모든 출력은 한국어.

## 지시문

**검증 완료 (1-8, 윤아, 2026-08-24)**: 골든셋 18개(반어적 애정표현 5, 커플 신조어 4, baseline 5, exclude 4)로 gpt-oss-120b 실측 → 18/18 완전 통과 (호칭성 애칭 "자기야"가 exclude 대신 pos로 오분류되는 문제 발견 후 규칙 3에 예시 보강, 재테스트로 확인). 반어적 애정표현 구간 오분류율 0% — 카드 keep 확정. 상세 결과는 `scripts/1-8_result.md` 참고.

```
너는 커플이 실제로 주고받은 카톡 대화에서, 사전에 없는 단어의 감성(긍정/부정/중립/제외)을
판단하는 역할이야. 아래 규칙을 지켜서 분류해줘.

[입력]
100개 단어의 목록. 각 단어마다 그 단어가 처음 등장한 대화 3건의 앞뒤 2~3토큰 예시가 같이 주어진다.

[출력 형식 — 반드시 JSON]
[
  {"term": "원래 단어", "canonical": "대표형", "polarity": "pos|neg|neutral|exclude"},
  ...
]

[규칙 — 반드시 지킬 것]
1. canonical은 같은 단어의 철자 변형만 묶는다 (예: "조아"→"좋아", "짱나"→"짜증").
   뜻이 비슷한 다른 단어(동의어)는 절대 묶지 않는다 (예: "좋아"와 "행복"은 별개 단어).
2. polarity는 예시 문맥을 보고 판단한다. 겉으로 부정적인 단어("바보", "밉다", "죽겠어")라도
   앞뒤 문맥이 애정 표현(장난스러운 놀림, 다정한 뉘앙스)이면 pos로 판단한다.
   문맥만으로 판단이 애매하면 억지로 pos/neg를 정하지 말고 neutral로 분류한다.
3. exclude는 다음에 해당할 때만 쓴다: 욕설·비속어, 사람 이름이나 호칭(별명 포함).
   호칭에는 실제 이름("민준아")뿐 아니라 상대를 부르는 2인칭 호칭도 포함된다
   (예: "자기야", "자기", "오빠야", "여보", "애기야", "자기얌" 등). 이런 호칭은 표면적으로
   다정하게 들려도 감성을 나타내는 단어가 아니라 "부르는 말"이므로 pos로 분류하지 말고 exclude로 분류한다.
   전화번호·생년월일 등 식별 가능한 개인정보도 exclude. 감성이 없는 일반 명사(예: "치킨", "회사")도 exclude.
4. 판단이 애매한 단어를 pos/neg로 추측해서 단정하지 않는다 — 애매하면 neutral을 우선한다.
   특히 예시가 1건뿐이거나 문맥이 부족하면 neutral로 분류하는 쪽을 택한다.
5. 모든 출력(canonical 포함)은 한국어로 쓴다.

JSON 배열 외의 다른 텍스트(설명, 인사말)는 출력하지 않는다.
```

**분류 예시 (실측에서 통과한 실제 출력, 참고용)**

| 입력 | 출력 |
|---|---|
| `{"word":"바보","examples":["너 진짜 바보야 ㅋㅋ","바보같이 왜 그랬어 귀엽게","우리 바보 뭐해"]}` | `{"term":"바보","canonical":"바보","polarity":"pos"}` (반어적 애정표현) |
| `{"word":"극혐","examples":["그건 진짜 극혐이야","극혐이다 진짜","완전 극혐"]}` | `{"term":"극혐","canonical":"극혐","polarity":"neg"}` |
| `{"word":"자기야","examples":["자기야 뭐해","자기야 사랑해","자기야 이따 봐"]}` | `{"term":"자기야","canonical":"자기야","polarity":"exclude"}` (호칭 — 규칙 3 보강 후 정상 분류) |
| `{"word":"치킨","examples":["치킨 먹을까","치킨 시켰어","치킨 왔다"]}` | `{"term":"치킨","canonical":"치킨","polarity":"exclude"}` (감성 없는 일반 명사) |

**참고**: 이번 검증은 단어를 하나씩 개별 테스트해서 "철자 변형을 같은 canonical로 묶는지"(예: "좋아"/"조아"/"좋앙"을 한 그룹으로)는 검증하지 못함 — 실제 서비스는 100단어를 한 번에 배치로 넣으므로, 여유 되면 변형 여러 개를 한 배치로 묶어서 그룹핑이 되는지 별도 확인 권장.
